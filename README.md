# Md. Niamul Islam — Portfolio

A responsive, static portfolio site for Md. Niamul Islam. It uses plain HTML, CSS and
JavaScript, so it can be previewed locally or deployed to Vercel without a build step.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy to Vercel

Import the GitHub repository into Vercel and leave the framework preset as **Other**.
No build command or output directory is required; Vercel serves `index.html` from the
project root.

## Privacy

The source CV PDF is excluded from Git. The public portfolio includes professional
contact details, but not the CV's home address or referee details.
